# get_next_line 🎉

Read files, one line at a time. Because why binge-read when you can savor every line? This project makes file reading precise, efficient, and just a bit more fun.

## Features:

- Reads a single line from a file descriptor, no matter how long it is.

- Handles multiple files simultaneously like a multitasking pro.

- Buffer size? Your call. Configure it to suit your needs.

Designed for developers who appreciate control, efficiency, and the joy of solving one problem at a time.

Happy coding! 🚀
